# Flats Page

A simple static real estate landing page named **Sunrise Avenue**.

## Files

- `index.html` — main page markup
- `style.css` — custom page styling

## Description

This project showcases a small flats listing experience with a home page, a list of available flats, and details pages for 2BHK, 3BHK, and 4BHK options.

## How to run

1. Open `index.html` in your web browser.

## Notes

- The page uses Bootstrap 4 and Google Fonts from CDN links.
- It also loads an external script from `https://new-assets.ccbp.in/.../static-ccbp-ui-kit.js` for page behavior.
- There is no local JavaScript file in this project.
